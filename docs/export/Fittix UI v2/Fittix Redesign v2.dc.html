02

Layout & information hierarchy

1Header

Dumbbell logo, Help and today's date as plain text (click the date for the full date and a live clock). During a find, a violet filter pill appears, so indexes are never ambiguous. Click it to list all clients again. File → Exit is gone; the window's close button does that.

2Client list

Compact cards, index badge first. The selected client's badge turns lime. Each card adds a one-line summary (plan size, next session). Long names wrap instead of being cut off.

3Client detail

2×2 profile grid, so long emails and addresses wrap in full. Below it, the workout plan, grouped Mon→Sun. Exercise tiles carry their plan index; today's row is flagged so the next set is obvious.

4Context column

Three record types, three signals: amber square = diet, violet dot = scheduled sessions (next one filled), lime check = completed history. Body progress and Payments sit below them, so the right column is about as tall as the centre. The last card in each column stretches, so all columns end on the same line. Empty cards shrink to just their header.

5Terminal panel

Closed by default, so the content fills the window. It opens on the first keystroke, on Help, or from the Terminal button. Drag the top edge to resize it, VS Code-style; the content above scrolls instead of shrinking. Esc or × closes it.

6Command input

Sits at the bottom of the terminal. No box, just a prompt on a hairline. Coral means an error. A quiet hint shows ↵ run · ↑↓ history. Usage hints from MESSAGE_USAGE appear only while typing.

Reading orderWho · name, index, goal→What today · flagged plan row→What's next · violet session→Feedback · terminal, on demand

States via PseudoClass

JavaFX has no :focus-within. Register focused-field and error PseudoClasses and toggle them on the HBox from the TextField's focus listener and CommandBox's existing failure path.

Results as a list

Swap ResultDisplay's TextArea for a ListView of a small record (command, success, feedback, usage). Append on every execute, then scrollTo(size-1). Cap at ~50 items. No model changes.

Derived, not new, data

Day grouping, "next session", "today" and macro bars are computed in the UI layer from existing fields. Load fonts with Font.loadFont at startup; no box-shadows needed (use surface steps).

Terminal toggle & resize

Open and close the terminal by adding or removing its VBox in the SplitPane's getItems(), then restore the saved divider position (persist it in GuiSettings). Put a Scene-level KEY_TYPED filter in place: when the terminal is closed and a printable key is typed, open it, focus the TextField and pass the character on. A KEY_PRESSED filter handles Esc (close).

Wrap, don't truncate

Set wrapText=true on the profile, list-card, tile and session labels, and bind their maxWidth to the column. Keep the ScrollPane at fitToWidth=true so only vertical scrolling appears. Empty cards render their header and an empty Region with a min height.
