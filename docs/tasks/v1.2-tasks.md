## T1: Support partial name matching in find

**Goal:** `find` matches names by case-insensitive substring instead of whole words. Multiple keywords stay OR.

**Changes**

1. `src/main/java/seedu/address/commons/util/StringUtil.java`
   - Add `public static boolean containsIgnoreCase(String sentence, String keyword)`.
   - `requireNonNull` both args. `checkArgument` that the stripped keyword is non-empty, same message style as `containsWordIgnoreCase`.
   - Return `sentence.toLowerCase(Locale.ROOT).contains(keyword.strip().toLowerCase(Locale.ROOT))`.
2. `src/main/java/seedu/address/model/person/NameContainsKeywordsPredicate.java`
   - In `test`, replace `StringUtil.containsWordIgnoreCase` with `StringUtil.containsIgnoreCase`. Nothing else changes.
3. `docs/UserGuide.md`
   - In the `find` section, replace "Only full words will be matched" with "Partial words are matched, e.g. `Han` will match `Hans`."

**Tests**

- `StringUtilTest`: `containsIgnoreCase` with null sentence, null keyword (both throw `NullPointerException`); blank keyword throws `IllegalArgumentException`; prefix match, middle match, different case, no match.
- `NameContainsKeywordsPredicateTest`, add:
  - `["pau"]` matches `Alice Pauline`
  - `["ALI"]` matches `Alice Pauline`
  - `["xyz"]` does not match `Alice Pauline`
  - `["zzz", "bob"]` matches `Alice Bob`
- `FindCommandTest`: run it. If substring matching changes an expected result, update the expected list.

**Done when** `find pau` lists Alice Pauline in the sample data and `find ALEX` equals `find alex`.

## T2: Add Goal class to model

**Goal:** a standalone immutable `Goal` value class for the upcoming `g/` field. Not used anywhere yet.

**Changes**

1. New `src/main/java/seedu/address/model/person/Goal.java`
   - `public static final String MESSAGE_CONSTRAINTS = "Goal must contain 1 to 50 characters, including at least one letter or digit.";`
   - `public static final int MAX_LENGTH = 50;`
   - `public final String value;`
   - Constructor `Goal(String goal)`: `requireNonNull(goal)`, `checkArgument(isValidGoal(goal), MESSAGE_CONSTRAINTS)`, `value = goal.strip()`.
   - `public static boolean isValidGoal(String test)`: after `strip()`, return true only if
     - length is 1 to `MAX_LENGTH`
     - matches `[^\p{Cntrl}]+` (rejects line breaks and tabs)
     - matches `.*[\p{L}\p{N}].*` (at least one letter or digit)
   - `toString()` returns `value`. `equals` compares `value` exactly. `hashCode` returns `value.hashCode()`.
   - Javadoc on class and all public methods.

**Tests:** new `src/test/java/seedu/address/model/person/GoalTest.java`

- `new Goal(null)` throws `NullPointerException`.
- `new Goal("")` throws `IllegalArgumentException`.
- Invalid: `""`, `"   "`, `"!!!"`, `"Fat\nloss"`, 51-character string.
- Valid: `"Fat loss"`, `"5"`, `"Run 5km in < 25 min"`, `"Muscle gain (upper body)"`, 50-character string, `"  Fat loss  "`.
- `new Goal("  Fat loss ").value` equals `"Fat loss"`.
- `equals`: same object, same value, different value, null, different type.

**Done when** only `Goal.java` and `GoalTest.java` are added and no other file changes.
